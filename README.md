# colinshevlin.blog

Based on [blog base](https://github.com/cwshevlin/blog-base). 

## To add a page

0. Create a [venv](https://docs.python.org/3/library/venv.html) and pip install
1. Create a file in content/
2. Copy the metadata fields from one of the existing files in content/
3. Write your thing
4. `make html`
5. `make serve` and navigate to localhost to view your thing
